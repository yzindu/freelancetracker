# Freelancer Project & Income Tracker

A full-stack web application designed for freelancers to efficiently manage clients, track project lifecycles, record income and payments, and visualize earnings through interactive analytics.

## Tech Stack
- **Frontend:** React (Vite), Vanilla CSS, Recharts, React Router DOM, React Icons
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose ODM
- **Authentication & Security:** JWT (JSON Web Tokens), bcryptjs
- **Utilities:** Axios, Express-Validator, jsPDF

## Directory Structure
- `server/` - Express REST API, Mongoose Models, Controllers & Middleware
- `client/` - React frontend application
- `screenshots/` - Feature previews and demonstration images
